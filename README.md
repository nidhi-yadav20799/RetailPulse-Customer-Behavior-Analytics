# RetailPulse – Customer Behavior Analytics & Revenue Intelligence Platform

A Data Science project for analyzing retail customer behavior using the Online Retail II dataset.

## Features

- Exploratory Data Analysis (EDA)
- Data Cleaning Pipeline
- Business KPI Analysis
- Customer Segmentation (RFM & K-Means) *(In Progress)*
- Churn Prediction *(Upcoming)*
- Revenue Forecasting *(Upcoming)*
- Streamlit Dashboard *(Upcoming)*

## Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Scikit-learn
- Streamlit
